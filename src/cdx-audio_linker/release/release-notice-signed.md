### Signature de code

L'exécutable et l'installateur de cette version sont signés numériquement. Voir la [politique de signature de code](https://github.com/Crazyshouby/cdx-windows/blob/main/src/cdx-audio_linker/CODE_SIGNING_POLICY.md) : *Free code signing provided by SignPath.io, certificate by SignPath Foundation.*

Si Windows SmartScreen affiche malgré tout un avertissement, la réputation d'un éditeur se construit avec le nombre de téléchargements : cliquez sur « Informations complémentaires » puis « Exécuter quand même », après avoir vérifié l'empreinte.
